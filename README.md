# Auto CKG KlikPro — Landing Page

Halaman promosi statis satu berkas (`index.html`) untuk Tools Auto CKG dan Jasa Input CKG KlikPro.

## Jalankan

Buka `index.html` langsung di browser, atau layani folder ini dengan server HTTP statis. Tidak ada dependensi, backend, database, login, atau build step.

## Deploy Vercel

Impor repository ini ke Vercel, framework **Other**, root directory `/`, build command kosong, output directory kosong. Domain khusus `autockg.web.id` dapat ditambahkan sendiri di Settings → Domains.

Pemesanan selalu diarahkan ke halaman produk/jasa resmi di `klikpro.cloud`. Video memakai embed YouTube (memerlukan koneksi internet).
